## Architecture notes

- **shadcn/ui config** (`components.json`): style is `base-nova`, built on `@base-ui/react` — **not** Radix UI. Don't assume Radix primitive APIs when reading or editing `components/ui/*`.
- **Tailwind v4, CSS-first config**: there is no `tailwind.config.*`. Theme tokens (colors, radii, sidebar/chart palette) live in `app/globals.css` under `@theme inline` and `:root`/`.dark`, and `shadcn/tailwind.css` is imported directly. Add/edit design tokens there, not in a JS config file.
- **Path alias**: `@/*` maps to the repo root (`tsconfig.json`), matching the shadcn aliases in `components.json` (`@/components`, `@/lib`, `@/hooks`).
- **Planned stack not yet wired up**: `@supabase/ssr`, `@supabase/supabase-js`, and `groq-sdk` are dependencies but have no client setup, env config, or usage in the codebase yet — there's no established pattern to follow for Supabase client creation, RLS-aware queries, or Groq calls. The first implementation will set the convention.
